# 个人研究与个性化调仓使用说明

## 第1章 功能入口

正式服务加载本次版本后，从研究工具、交易复盘和调仓方案进入。既有独立静态演示包保留原版本；本次新增功能在正式前端执行实际服务调用，不通过静态成功标签模拟计算。

| 功能 | 页面入口 | 用户操作 | 得到的结果 |
| --- | --- | --- | --- |
| 我的研究系统 | 研究工具 | 选择数据工具、设置指标和观察助手、保存版本 | 私有个人研究技能，可更换标的重复运行 |
| 自定义指标 | 我的研究系统 | 组合比率、差值或加权平均，可引用其他个人指标 | 确定性数值、单位、资料期间和观察提示 |
| 长期投资偏好 | 交易复盘 | 保存换手、现金与微调偏好，确认候选 | 由显式偏好与已确认交易账本形成的可计算风格政策 |
| 调仓偏好对比 | 调仓方案 | 读取当前持仓、编辑目标百分比、生成对比 | 基础与个人方案的目标、股份数量、费用、现金与风险 |
| 原资料重算 | 研究系统运行结果 | 对已保存的真实事实选择重算 | 保留原时点输入，重复应用指标和研究方法 |

## 第2章 个人研究系统

1. 在研究工具页选择“采用盈利质量观察”，或新建系统。
2. 资料助手绑定已安装、验证并允许当前账户调用的具体技能版本。指标助手按中文配置执行公式，观察助手按阈值给出研究提示。
3. 保存后输入六位标的代码及报告期，运行已保存系统。多期财务资料必须明确期间；缺单位、未知单位、零分母或冲突资料不会生成数值。
4. 保存的定义可在其他标的上复用，也可由AI投资助手通过个人研究工具调用。聊天不能指定其他账户、更改公式或绕过停用。
5. 真实输入已保存时，可选择“用本次已保存资料重算”。该操作也接受研究准入、预算和取消控制。

## 第3章 长期风格与方案对比

1. 在交易复盘页保存单次换手上限、现金保留比例和微调忽略幅度。空白项采用明确的候选默认值，资料不足不会冒充已观察到稳定风格。
2. 已确认成交记录用于产生风格候选；点击“确认并用于调仓”后才生效。行为风格控制调整节奏，已确认投资者画像继续决定风险预算与适当性。
3. 在调仓方案页点击“读取当前持仓并设置目标”，编辑各资产目标百分比；合计必须为100%。也可使用既有组合优化生成的目标。
4. 生成对比后查看原始目标、本次个人目标和实际整手数量。换手预算不足时，本次只接近部分原目标，不表示完整目标已经达成。
5. 偏好、成交账本或画像改变后，旧政策失效并清除旧对比。重新确认后才允许使用新参数计算。

价格、资产类型和交易单位来自同一服务端持仓快照，不能通过目标表覆盖。现金或风险条件与换手节奏冲突时保留复核状态；系统不自动提交交易。

## 第4章 功能展示示例

| 条件 | 基础方案 | 个人方案 | 说明 |
| --- | --- | --- | --- |
| 组合与目标 | 10万元；资产一现有3,500股、每股10元，目标15% | 同一输入；确认5%单次换手上限 | 全部为受控演示数据 |
| 实际减仓 | 2,000股、20,000元 | 1,000股、10,000元 | 个人方案本次目标25%，分步接近15% |
| 换手与费用 | 10%；15.20元 | 5%；10.10元 | 数量、费用由服务端计算 |
| 扣费后现金 | 34,984.80元 | 24,989.90元 | 仍需通过各自风险检查 |

实际账户结果取决于当前已确认持仓、行情、资料和画像。本次示例证明功能执行和输出差异，不证明投资收益。
