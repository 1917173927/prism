# Prism 前端主题与产品 Demo

## 第1章 入口与使用方式

1. 在项目根目录双击 `start-product-demo.cmd`，页面会自动打开。首次启动的窗口需保持打开，关闭窗口将停止服务。运行环境为 Python 3.9 或以上。
2. 入口为 `http://127.0.0.1:8860/demos/product-demo/#overview`，通过左侧导航切换页面。重复双击复用已有 Demo；项目环境、Windows Python 启动器和系统 Python 按顺序检测。
3. 点击“截图模式”，或使用 `http://127.0.0.1:8860/demos/product-demo/?capture=1#overview`。演示工具栏隐藏，“演示数据”标记持续显示。
4. 未打开引用时按 `Esc` 退出截图模式；引用打开时先关闭引用。点击“重置演示”恢复预设状态。
   手机通过顶部小图标退出截图模式，再点击“重置演示”。
5. 本入口只需 Python 标准库，绑定本机地址；不启动业务 API，不要求账户、数据库或数据服务凭据。8860 被其他服务占用时，启动窗口保留错误提示，可用 `start-product-demo.cmd --port 8861` 指定可用端口。

## 第2章 页面与演示交互

| 页面 | 主要展示 | 演示操作 | 地址片段 |
| --- | --- | --- | --- |
| AI 投资助手 | 固定研究说明、声明及关联资料 | 示例问题、文字提交、引用查看 | `#copilot` |
| 组合总览 | 资产、收益、配置、持仓及风险 | 组合图表、跨页研究入口 | `#overview` |
| 市场观察 | 指数日线、基础指标及观察板块 | 指数、日／月周期切换 | `#market` |
| 交易复盘 | 行为指标、近期记录、研究习惯 | 查看固定行为样例 | `#trading-style` |
| 投资偏好 | 画像、评级、问卷摘要及解释偏好 | 三个子标签、解释详细度 | `#profile` |
| 研究工具 | 固定九项工具及可用状态 | 搜索、分类、演示选择 | `#skill-store` |
| 研究资料 | 演示资料、主体、期间及片段 | 关键词匹配、引用抽屉 | `#research-knowledge` |
| 研究任务 | 研究目标、阶段进度及资料缺口 | 运行固定演示、取消 | `#live-research` |
| 风险分析 | 波动环境、资产联动、市场风格资料缺口 | 展开计算说明与矩阵 | `#research-algorithms` |

研究任务页的运行是本地步骤演示；工具选择只影响演示状态。资料检索为固定文档关键词匹配，未调用模型或实际混合检索。未覆盖的自由问题明确返回演示未覆盖，引用的存在不冒充真实论文、公告或财报支持。

风险页先说明投资用途：波动概率描述价格起伏状态，不是涨跌概率；资产联动输入为三个独立合成资产，未关联账户持仓；市场风格因素不等于个人持仓收益归因。算法方法、参数与矩阵可展开查看。投资者 C3 等级与组合风险分别标注。市场收益与波动随选中指数同步切换，板块保留固定观察集说明。

## 第3章 样式与数值边界

| 领域 | 统一约定 | 实际实现 | 保留约束 |
| --- | --- | --- | --- |
| 主色 | 白／浅灰面板、橙色强调 | 共享 `design-tokens.css` | 深浅主题保持独立色值 |
| 字体 | 中文无衬线，金额和状态等宽 | 标题 28／24／18 px | 字体使用本机资源 |
| 组件 | 卡片 16 px、按钮 38 px、间距以 4 px 为单位 | `product-theme.css` 与 Demo 样式 | 正式导航及子页显隐保留 |
| 图表 | 现有 Lightweight Charts 5.2.1 | 本地打包资源 | 隐藏、重显、缩放释放旧资源 |
| 数值 | 固定合成样例 | Python Decimal、NumPy、既有论文算法 | 浏览器不计算风险、调仓或金融指标 |
| 数据边界 | “演示数据”持续标注 | 固定快照、本地状态、零数据服务／模型调用 | 不读取或写入真实用户资料 |

`tools/build_product_demo_data.py` 可重建冻结快照；HMM 和协方差采用现有确定性算法计算合成输入，五因子缺完整输入时保持 `UNAVAILABLE`。产品截图用于展示界面，不作为真实行情、上游配额、研究质量或投资建议的验收材料。
