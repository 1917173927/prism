# Prism 工程优化实施计划

## 第1章 范围与约束

实现 TASK-01 至 TASK-05，并修复截图中的分析过程、行业点击结果位置及三项任务卡片。按用户最新要求，本轮不调整侧边栏与页面分区。保留原有 README.md 和 docs/prd-integration-guide.md 的用户改动。

所有金融计算在 Python 执行，前端只处理输入和展示。app.js 保持禁用 HTML 字符串写入。全量 pytest 不少于 492 例，新增核心行为回归测试和浏览器交互验证。

## 第2章 设计决策

| 范围 | 当前证据 | 可选路径 | 采用方案 |
| --- | --- | --- | --- |
| 行情 | 自动建档在 main.py，单一腾讯源，失败生成虚构底稿 | 全面替换官方供应商；独立快照链 | 独立主备静态快照链；总预算 2s，单级上限 1.5s；不改变 SkillHub 的官方数据失败语义 |
| OCR | 正则和默认数量；无金额平衡 | 让模型纠错；本地编辑距离和 Decimal 校验 | 本地纠错与逐行复核，不自动改变真实零股持仓 |
| 调仓 | 实现在 service/portfolio_rebalancing.py 和 rebalancing/contracts.py | 另建重复模块；扩展现有契约 | 扩展现有服务，整手、费用、净现金、未报价新资产拒绝执行 |
| 情景 | simulation/ 和 service/scenario_simulation.py 为固定剧本 | 修改固定剧本契约；新增自定义请求 | 新增独立自定义压力测试，明确协方差假设与 VaR 时间口径 |
| 前端 | 任务卡使用写死结论，关键上下文分散 | 引入框架全面重写；轻量状态管理 | Micro-Store 原子上下文切换和请求作废，直接渲染后端分析；导航和分区保持不变 |
