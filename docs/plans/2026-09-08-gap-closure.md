## 第3章 方案选择

1. 全面替换前后端与数据库，或在现有服务上增量接入。选择增量实现，以保留现有接口、账户数据、浏览器流程和回归覆盖。
2. 对调仓直接扩大整手交易，或以约束检查驱动候选交易并重新体检。选择后者，约束不满足必须保留复核或阻断；不强制生成交易。
3. 自建身份认证系统，或对接标准身份提供方。用户确认本地部署且无现成身份服务后，采用标准 HTTP Basic 和 scrypt 密码摘要；保持可选配置，未宣称公网生产认证完成。
4. 工作流复用成熟图引擎并接通既有执行器；不自研图形内核。长期记忆只保存用户确认、可追溯的信息，原始凭据不进入检索库。
