### 二、运行口径

截图均采自 2026 年 11 月 18 日运行的本地 Prism 工作台，原始尺寸为 2880 × 1620。图 4 使用运行时读取的同花顺行情和行业数据。其余图使用同一隔离账户的合成持仓与问卷。对话以模拟模式建立会话，持仓诊断、风险判断和调仓测算通过各功能入口调用后端计算服务。本案例的行业暴露来自股票直接归类。调仓方案为假设测算，已核验账户持仓在测算前后相同。
