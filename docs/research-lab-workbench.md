# 持续研究与资金规划使用说明

## 第1章 功能入口

| 页面 | 功能 | 操作 | 输出 |
| --- | --- | --- | --- |
| 研究工具 | 描述创建研究方法 | 生成/修改草稿，预览并确认保存；可载入最近草稿 | 已保存的个人技能与指标分工 |
| 研究工作台 → 开展研究 | 投资假设跟踪 | 选择方法和指标、报告期、条件与检查间隔，确认订阅 | 观察状态、资料缺口与变化记录；可停止 |
| 研究工作台 → 查找资料 | 公告关联持仓 | 上传具有代码/时点的公告或财报，选择当前版本分析 | 原文差异、直接及基金披露路径、已知敞口 |
| 持仓分析 → 更多分析 → 市场变化模拟 | 方法模拟比较 | 读取组合，配置两套规则与目标，创建并推进 | 同基线虚拟权益、费用、换手及回撤 |
| 持仓分析 → 更多分析 → 调仓方案 | 资金用途规划 | 设置目标、期限和确认现金流，保存并计算 | 日期资金分配、缺口与受约束调整方案 |

交易风格与长期偏好位于持仓分析的交易风格标签。历史 `#live-research`、`#research-knowledge`、`#research-algorithms` 地址仍可直达研究工作台的对应标签；`#trading-style` 兼容原入口。

## 第2章 研究方法与假设

1. 净利率和百分比阈值可由明确语义规则直接解析；其他描述使用当前管理员配置模型。模型只能提出目录内的定义草稿，未配置模型或不支持的算子会显示缺口。公式由程序执行，确认前没有新技能。
2. 假设的阈值需与指标单位一致。趋势使用三个递增的指定报告期，比较两次变化，不推断缺失期间。启用后默认每24小时复核，可设置60秒至7天；服务每10秒检查到期订阅，最多4项监测并行，仍使用全局研究准入。
3. 当前账户可访问的新财报进入资料库后，已确认的跟随订阅可推进观察期。方法变更、停用或资料不足不能形成有效判断；相同内容不重复记为变化，停止订阅及服务关闭传播取消。

## 第3章 公告与模拟

公告关联仅接受明确六位主体代码和已发布的公告/财报。路径金额取自当前服务端组合，基金仅按披露比例计算，剩余部分单列；资料更正或删除使旧引用记录失效，文本关系不作为涨跌预测。

模拟首期支持当前组合中的股票、ETF整数持仓和人民币现金，2—5套策略必须使用同一基线、共同费用和风险条件。页面提供两套，更多可经结构化API设置。规则连接研究指标与条件满足/不满足的目标，每次用可信当前报价推进。无新报价不重复模拟；资料不足、体检或完整风险预算不通过不改变虚拟数量和现金。画像、政策、方法或数据模式变化要求新建实验。只交付前向记录，历史回测须另有完整历史时点数据。

## 第4章 资金目标与状态

金额及已确认现金流以人民币表示。同一日期先计入现金流，再按目标优先级分配；未来收入不提前使用，同一笔资金只分配一次。目标不足仍显示缺口；不假设资产收益或达标概率。调整目标只增加预留，不因目标减少而自动降低当前现金比例；测算复用已确认画像和可用长期风格，交易费用或风险不足保留复核。

保存新的目标版本清除旧结果；持仓、行情、画像或政策变化后，旧测算显示历史失效并要求重新计算。所有输出为研究或虚拟测算，真实组合和交易账本不会由这些功能修改。
