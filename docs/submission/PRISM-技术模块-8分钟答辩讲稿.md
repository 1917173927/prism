# PRISM 技术模块 8 分钟答辩讲稿

## P1 系统总体分层架构（约 50 秒）

PRISM 首先把语言交互、金融计算和建议审查分开。用户通过工作台或对话入口提出问题，大模型只负责识别意图、提取槽位和生成通俗解释。只有经过确认的结构化输入，才能进入研究与计算层。金融数据由 Provider 获取，研究任务由有界 DAG 调度，金额、权重、穿透暴露、HHI 和调仓数量全部由确定性模块计算。最后，风险闸门与合规闸门独立裁决。只有两个闸门同时通过，系统才生成 DecisionReceipt，并保存 DecisionEvent 供后续审计和回放。

## P2 前后端技术栈与环境（约 35 秒）

前端采用原生 HTML、CSS 和 JavaScript，通过 Hash 路由组织页面，SSE 提供流式对话，AntV X6 承载工作流画布，Lightweight Charts 负责行情图。后端使用 Python 3.11 或 3.12、FastAPI、Pydantic 和 Uvicorn，金融计算统一使用 Decimal。默认存储是 SQLite，也提供 PostgreSQL 适配。右侧展示的是真实 OpenAPI 路由，说明系统不是概念架构，而是具备完整接口边界的可运行模块化单体。

## P3 与同花顺 SkillHub 平台集成方案（约 40 秒）

底层问财 SkillHub 已通过项目内九项版本化 Skill 清单接入，覆盖公告、新闻、研报、行情、财务、行业、宏观、基金和可转债。PRISM 不改造平台底层，而是在上层新增画像编译、证据校验、组合计算、序贯再平衡和双闸门。上方问财 APP、iFinD 机构工作台和外部 API 属于目标交付入口，因此图中使用虚线，不把尚未完成的平台内上线表述为当前成果。

## P4 部署与交付形态（约 30 秒）

项目支持两类部署形态。演示环境是当前可运行的单机模式，浏览器与 FastAPI 同源部署，SQLite 使用 WAL，凭据在 Windows 下通过 DPAPI 保护，并按 owner 隔离数据。生产落地可以替换为 PostgreSQL，并在前方接入身份服务、反向代理、限流和监控。后者属于部署建设项。无论采用哪种部署，系统都保持 Advisory Only，不接管账户、不生成订单、不执行交易。

## P5 完整业务工作总链路（约 45 秒）

以“我想控制回撤，这套持仓需要怎么调整”为例。用户先完成注册和归属确认，再通过 19 题问卷生成八维画像与 C1 到 C5 适当性等级。持仓可以通过文本或截图 OCR 导入，低置信内容必须人工确认。系统把问题转为研究计划，由 DAG 执行专业节点，再把 Provider 结果转换为 Evidence、Fact 和 Finding。风险与合规双闸门通过后，才输出带来源、风险和失效条件的报告与回执。每一条建议都绑定同一用户的画像版本、持仓快照和证据引用。

## P6 AI 对话多轮交互链路（约 45 秒）

多轮对话的重点不是保存更多文本，而是防止旧状态污染新计算。系统把短期消息窗口、中期会话事实和长期显式记忆分开。进行金融分析前，服务端锁定画像版本、持仓版本和数据模式，并计算 SHA-256 指纹。请求必须携带预期修订号，发现漂移后停止沿用旧结论。普通交流可以由模型回答，金融查询必须进入 Provider 和证据链，持仓测算必须进入确定性工具。最终通过 SSE 返回内容、来源和状态。

## P7 持仓分析与再平衡工作链路（约 50 秒）

持仓分析先完成数据确认，再把基金和 ETF 穿透到底层资产和行业，计算 HHI，并与当前画像的风险预算比较。识别超限项后，系统生成目标权重，但不会停留在金额层。它先过滤 0.50% 的小偏差，严格先卖后买，再按 100 股整手、有效报价、印花税、过户费、佣金和现金下限计算可执行数量。买入手数使用二分法寻找可承受最大值。最后重新构造交易后组合并执行完整体检。该算法属于序贯确定性求解，不宣称全局最优。

## P8 自研算法① 画像、风险与证据验证（约 55 秒）

第一组算法把 19 题问卷转换为八个 0 到 100 分维度，并形成 C1 到 C5 适当性展示。为了兼容当前确定性闸门，系统再把有效画像编译为保守、平衡和成长三档内部规则，并生成单一资产、行业、科技行业和未分类暴露上限。因此画像不是展示标签，而是计算参数。第二组算法解决多智能体重复同一信息的问题。验证器只认可显式 lineage，同一来源的多条记录先去重。至少两个独立来源一致，事实才进入 SUPPORTED。来源冲突或数据不足会保留为复核状态。

## P9 自研算法② 组合计算与任务调度（约 50 秒）

左侧算法解决基金表面分散、底层集中看不见的问题。股票直接按 100% 归属，基金和 ETF 按披露成分拆分，没有披露的残值必须保留为未分类。直接暴露、穿透暴露和未分类暴露严格闭合组合总值，HHI 在权重取整前计算。右侧是有界 DAG。研究计划提前固定拓扑、节点超时和总截止时间，依赖就绪的节点并行运行。必需节点失败会使运行失败，可选节点不完整只能降级为部分结果，失败不会被静默改写为成功。

## P10 自研算法③ 决策控制与会话记忆（约 50 秒）

最后四项控制共同决定建议资格。离散再平衡把目标金额转换为受整手、费用和现金约束的数量。双闸门独立审查风险与合规，状态聚合遵循阻断优先、复核其次、通过最后，只有双 PASS 才能输出正式建议。分层记忆用 revision 和指纹阻止旧状态进入新计算。历史检索始终标记为 Historical Only，必须由用户确认恢复，恢复后还要清空旧的研究、优化和建议结果。这些机制使计算可复算、过程可追踪、输出可阻断、历史可受控恢复。
