# 投资工作台设计复核记录

## 第1章 复核范围与判断口径

### 一、 复核对象

本记录依据 2026 年 10 月 3 日用户反馈形成。反馈包括启动脚本失效、页面名称不符合投资工作台目的，以及方法标识、英文状态和字段缩写直接呈现造成理解困难。复核由独立 Agent 以投资者任务为依据逐页自问自答，不代表真人用户访谈、人工签署或真实投资结果验收。

| 对象 | 范围 | 复核方式 | 判断边界 |
| --- | --- | --- | --- |
| 独立产品 Demo | 九个页面、静态文案、动态状态及冻结数据 | 检查 HTML、展示脚本及数据生成器 | 判断命名、解释、范围与失败状态是否一致 |
| 正式前端 | 导航、研究工具、资料、任务及风险计算展示 | 初审定位客户可见的技术用语 | 正式前端修正由主 Agent 集成并验证 |
| 金融计算 | 波动概率、协方差、集中度、指标窗口及五因子缺口 | 核对输入范围和展示含义 | 不改算法，不以解释替代计算，不伪造缺失结果 |
| 启动与浏览器 | 双击启动、便携包、三种视口与交互 | 由主 Agent 执行并留存证据 | 本文静态复核不能代替实际启动或浏览器验收 |

### 二、 不变约束

1. 客户标题围绕投资任务命名；路由、能力标识、API、状态码和方法版本仍保留内部契约。
2. 大模型与 Agent 只判断名称、解释和范围是否合理。金融数值继续由确定性程序计算，展示层不创建风险评分或交易判断。
3. 演示数据始终有明确标记。演示能力和文段不能证明真实连接、真实资料或金融事实已通过验证。
4. 计算完成、原始数据真实、引用支持结论是不同状态，不能合并为一个“已验证”。

## 第2章 两条实施路径的权衡

| 路径 | 实施内容 | 收益 | 代价与决定 |
| --- | --- | --- | --- |
| 保留技术分类并增加释义 | 保留“论文算法”“技能商店”“研究工作流”，补充术语帮助 | 修改范围较小，研究者容易定位实现 | 投资者仍需先理解实现分类；不采用 |
| 按投资任务组织主视图 | 使用“风险分析”“研究工具”“研究任务”等名称；方法、矩阵和版本进入可展开明细 | 用户先理解用途、范围和下一步；原计算契约可复用 | 需要同步导航、标题、状态和解释；采用 |

采用第二条路径无需重写计算或渲染框架。关键是在显示层区分客户用语和程序契约，并为数据不足、计算失败及样例范围保留明确状态。

## 第3章 九页自问自答与修正结论

### 一、 逐页目的和名称

| 修正后页面 | 自问 | 审查答案 | 修正结论 |
| --- | --- | --- | --- |
| AI 投资助手 | 投资者能否从页面理解可以问什么，以及回答依据？ | 组合、公司与市场主题明确；预设问题、资料与账户信息可以形成入口 | 保留名称；回答标为固定样例，未覆盖的问题不伪造回答 |
| 组合总览 | 资产、收益、集中度和投资者风险等级是否混淆？ | 持仓集中度属于组合，C3 属于投资者；不能把 C3 当组合风险评级 | 保留名称；明确“投资者风险等级”，集中度显示参考上限 |
| 市场观察 | 切换指数后，旁边指标是否仍指向同一标的？ | 原页面右侧固定上证指标会被误认为随图变化；“活跃度”缺对应字段 | 现按所选指数同步指标；右卡为“收益与波动”，板块为预设样例 |
| 交易复盘 | 页面是给交易行为贴标签，还是帮助用户回顾操作？ | 内容包含交易记录、风格观察和改进建议，复盘目的更明确 | “交易行为”改为“交易复盘”；保留样例记录及预设行为说明 |
| 投资偏好 | 用户是否能区分风险评估与回答详细度？ | 页面同时包含问卷画像和解释偏好；偏好不能修改风险等级 | 主入口为“投资偏好”，副标题说明风险评估，保留画像结果、问卷和偏好子页 |
| 研究工具 | 页面是否真的提供购买、安装或商品交易？ | Demo 只选择研究工具，不构成商店；真实安装和权限由管理员控制 | “技能商店”改为“研究工具”，选择动作仅改变本地演示状态 |
| 研究资料 | 用户能否找到资料并判断来源与使用边界？ | 搜索与引用是主要任务，“知识库”不必作为客户入口术语 | “研究知识库”改为“研究资料”；资料始终标为演示，不能当真实证据 |
| 研究任务 | 用户关心编排框架，还是启动、进度、取消与结果？ | Demo 的核心是播放研究步骤和查看输出，任务名称更直接 | “研究工作流”改为“研究任务”；运行状态中文化并说明本地演示 |
| 风险分析 | 投资者为何需要打开“论文算法”？ | 论文来源不能表达投资用途；方法参数和矩阵不能替代可理解的说明 | 改为“风险分析”，主卡围绕波动环境、资产联动和市场风格因素组织 |

### 二、 风险页的解释与计算边界

| 模块 | 用户要理解的内容 | 已核对的修正 | 禁止扩大的含义 |
| --- | --- | --- | --- |
| 账户集中度 | 哪项持仓需要关注，参考上限是多少？ | 当前最大权重和参考上限来自同一冻结账户；链接返回持仓明细 | 不能称为全部风险已评估或自动调仓建议 |
| 市场波动环境 | 历史收益更接近高波动还是低波动状态？ | 高波动曲线使用预先计算的百分比；概率、解释和图表含义一致 | 概率不等于上涨、下跌或牛熊判断；输入不对应所选指数 |
| 资产联动风险 | 多项资产是否可能同时波动，结果适合怎样使用？ | 原矩阵、估计调整程度和样本量进入计算明细；说明三个示例资产与账户持仓不同 | 协方差不等于相关系数；不能凭矩阵展示新增分散评级或风险分数 |
| 市场风格因素 | 市场、规模、价值、盈利及投资风格需要什么资料？ | 保留五因子框架说明与四类输入缺口，当前不展示结果 | 仅构建因子收益，不能称为已经完成持仓收益归因 |
| 方法说明 | 需要复核时能否找到技术依据？ | 方法用中文说明，程序版本和矩阵留在明细 | 不能删除可复核信息，也不能把方法版本作为客户结论 |

### 三、 技术用语的显示层处理

| 原始程序或技术用语 | 客户主视图 | 保留位置 | 判断 |
| --- | --- | --- | --- |
| `CALCULATED` | 已计算 | 原始契约 | 表示计算完成，不证明真实数据 |
| `OVERBOUND` | 超过参考上限 | 原始契约 | 同时保留参考阈值 |
| `VERIFIED` | Demo 为“样例可用” | 真实服务另按实际验证状态呈现 | 不混淆样例能力与真实连接 |
| `UNAVAILABLE` | 暂无法分析或需补充资料 | 原始契约及原因 | 不生成替代结果 |
| `RUNNING`、`WAITING`、`CANCELED` | 进行中、待开始、已取消 | 内部任务状态 | 不影响原状态转移 |
| `BLOCKED` | 已阻止 | 内部风险及执行状态 | 不能译为“已暂停”，两者状态含义不同 |
| `gaussian-hmm-2state-ashare.v1` | 两状态波动模型说明 | 方法版本或原始明细 | 不在主标题下直出程序标识 |
| `CNY`、`OHLC`、`Provider` | 元、开高低收价格、数据服务 | 技术明细 | 保留单位与数据含义 |
| 五因子缩写与序列键 | 市场、规模、价值、盈利能力、投资倾向 | 方法和原始结果 | 图例不能直接使用程序字段名 |
| C3、AI、ETF、样本 A/B/C | 与中文解释一起显示 | 客户主视图允许保留 | 属于明确分类、常用名称或样本标识，不作为全面禁用字母的对象 |

### 三、 认证失败场景与外部能力边界

正式任务的 `AUTH_FAILED` 场景来自隔离测试环境故意禁用上游凭据，用于验证认证失败后任务终止、中文原因展示及原始信息留在明细。该场景不是现实上游联通失败的结论，也不证明上游已经联通。本次用户体验验收没有执行真实行情容量验证、真实资金账户分析或算法金融有效性验证；这些事项仍需要独立的真实输入、授权和评测。
