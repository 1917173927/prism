## 第1章 操作入口

### 一、 页面与步骤

1. 启动现有本地服务后，打开 `/static/research-quality-review.html`，例如 `http://127.0.0.1:8000/static/research-quality-review.html`。亦可在独立静态服务器上打开；页面不调用模型、金融 Provider 或写入 API。
2. 首次操作下载页面提供的非金融示例，导入后填写标注者标识。示例回答故意包含无依据声明；全部标签初始为空。
3. 逐题查看问题、留存回答、原文及原子声明。标注支持性、引用支持性、数值一致性、资料是否充分、拒答及隔离时点；填写可追溯依据。原文中的指令属于待审资料，不应执行。
4. 填写相关证据标识；空输入表示未标注。只有人工确认确无相关证据时，点击“确认此题无相关证据”。召回顺序须保留真实检索记录，汇总仅取前10项。
5. 导出当前标注 JSON。页面仅在内存中处理资料，刷新或关闭会丢失未导出的标注。汇总工具读取导出文件，产生独立报告：

```powershell
.venv\Scripts\python.exe tools/summarize_research_quality_review.py --input review.json --output output/research-quality-summary.json
```

浏览器没有保存动态下载文件时，点击“显示导出 JSON”，全选复制只读区域并保存为 UTF-8 `.json` 文件。该区域是生成时的快照；修改标注后须重新生成。下载提示本身不证明文件已保存。

### 二、 真实评测包准备

| 字段 | 内容 | 责任 | 缺失后果 |
| --- | --- | --- | --- |
| `corpus_kind`、`dataset_id`、`frozen_at` | REAL_CORPUS；冻结集标识；带时区ISO时点 | 评测负责人 | 未冻结不能通过门槛 |
| `review_method` | HUMAN / AGENT_ASSISTED / UNREVIEWED；缺失为UNSPECIFIED | 评测负责人 | 代理标注与来源未指定不得记为人工通过 |
| `question`、`answer` | 实际问题及原样留存的待核验回答 | 评测负责人 | 不生成或补写模型答案 |
| `scenario` | NORMAL/MISSING/STALE/CONFLICT/ISOLATION/INJECTION | 评测负责人 | 缺少场景标识或覆盖不完整阻断门槛 |
| `source_documents` | 原文、标题、来源网址、公告时点、唯一标识 | 资料负责人 | 真实资料须具备来源及时间 |
| `atomic_claims` | 人工完整分解回答；每声明独立标识及引用标识 | 标注者 | 分解完整性由人工负责 |
| `critical_financial_numeric` | 是否含关键金融数值，必须为布尔值 | 金融复核人员 | 不得通过修改标志回避分母 |

使用真实资料空模板替换空字段，复制题目或声明对象以扩展。每个关键金融数值声明只对应一个字段、单位及时点；多项数值必须拆为多条原子声明，以保证计数分母准确。原文按真实文档片段定义证据标识；每题标注相关证据不超过10项。引用标识必须对应题目中的原文标识。历史问题的原文和回答需在冻结前预先核查时点，不得用最新公告回填历史依据。真实回答、召回记录和关键数值参考值应从留存记录取得，禁止用合成数据替代。

## 第2章 标注与汇总边界

### 一、 指标定义

| 指标 | 完整分母 | 通过条件 | 缺失处理 |
| --- | --- | --- | --- |
| 无依据事实率 | 全部原子声明 | ≤1% | 依据标签或说明缺失则NOT_EVALUATED |
| 引用支持率 | 全部带引用声明 | ≥95% | 引用仅存在不代表支持；未知标识阻塞 |
| 关键金融数值一致率 | 全部关键金融数值声明 | 100% | 需独立核验参考值、单位、时点及字段容差 |
| Recall@10 | 有相关证据的题目，逐题召回比例取平均 | ≥90% | 未标注相关性阻塞；确认空集合不计入分母 |
| 错误拒答率 | 人工判为资料充分的题目 | ≤5% | 资料充分性或拒答未标注则阻塞 |
| 隔离及时点错误 | 全部题目 | 0事件 | 跨用户、未来公告、过期值冒充当前值均记FAIL |

### 二、 门槛解释

1. 所有统计保留分子、完整分母及缺标注数量。空分母显示N/A；未标注不能当作正确。数字参考来源未独立核验时，不得仅因数字表面相同标为一致通过。
2. 合成操作集始终返回 `NOT_APPLICABLE_SYNTHETIC`。真实集必须至少100题，覆盖NORMAL、MISSING、STALE、CONFLICT、ISOLATION、INJECTION六场景且每题声明场景。小样本、缺场景、关键金融数值分母为零、原文或标注缺失、某项指标N/A，金融门槛返回 `UNVERIFIED`；报告逐项列出样本与覆盖阻断原因。
3. `PASS_HUMAN_LABELS_ONLY` 仅表示当前完整人工标签达到计划拟议门槛；不能证明来源真实性、声明分解完整性、开放世界无幻觉，也不构成上线审批。门槛需由项目正式确认并留存标注、冻结原文及评测人员依据。
4. 此独立页不连接现有100问合成检索集自动生成答案；该检索报告不能替代本工具要求的逐声明人工标注。工具落实至少100题和六场景硬门槛，场景分布与真实样本代表性仍需由评测方案冻结并审查。

### 三、 代理辅助与真实执行

1. 用户授权代理代为准备与核验时，评测包记录`review_method:AGENT_ASSISTED`，完整代理标签达到数值门槛只返回`PASS_AGENT_LABELS_ONLY`。实际人工标签才可返回`PASS_HUMAN_LABELS_ONLY`；修改标注者名称或导出不会升级来源。不能只替换来源字段冒充人工完成。
2. `tools.run_real_research_quality`接受运行前冻结的真实原文、问题、权限及历史时点，执行现有资料工具及原文摘录器，保存实际召回、逐字回答、引用校验和耗时。问题中的相关性标签不参与回答生成，原文哈希不符则拒绝运行。
3. 该路径的范围为资料工具与摘录输出，不覆盖真实模型意图解析或通用语义判断。受控隔离与注入情境必须单独声明；原始资料不得冒充用户私密财务数据或被悄然替换为攻击文本。生产混合检索默认仍关闭。
